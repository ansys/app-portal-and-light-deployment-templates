Ansys App Portal and One Node Deployment Templates 0.4.1#

Welcome to the documentation for the Ansys App Portal and One Node Deployment Templates™ platform.

The Ansys App Portal and One Node Deployment Templates™ platform provides all the containerized services needed to leverage single-node deployments for the execution of Ansys Web Applications (AWA). It is compatible with apps created with Ansys optiSLang® 24R2 or later.
