.. only:: internal

   .. list-table::
      :stub-columns: 1
      :widths: 25 75

      * - Project name:
        - ``saf-light-one-node``
      * - Package name:
        - ``ansys-app-portal-and-one-node-deployment-templates``
      * - Supported Python versions:
        - 3.9 to 3.11
      * - Supported operating systems:
        - Windows 11 or Windows Server 2022


The :program:`Ansys App Portal and One Node Deployment Templates™` platform provides all the containerized services needed to leverage single-node deployments for the execution of **Ansys Web Applications** (AWA).
It is compatible with apps created with Ansys optiSLang® 24R2 or later.

.. only:: internal

   It is one of the packages that are delivered as part of the Ansys Solution Applications Framework™ (SAF) initiative.
